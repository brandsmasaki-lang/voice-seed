# こえのたねの使い始め方

配布元：株式会社ブランズバンクシステムズ
公式案内：https://ai-no-tane.com/lp/koenotane/
ソースコード：https://github.com/brandsmasaki-lang/voice-seed

対応：AppleシリコンMac（M1以降）・macOS 26以降・日本語。
この配布物はDeveloper ID署名・Appleの公証を受けていません。ローカルのアドホック署名のみです。

## インストール

1. ZIPを展開し、「こえのたね.app」を「アプリケーション」へコピーします。
2. コピーしたアプリを開きます。
3. 開発元を確認できない旨の警告で開けない場合は、下記の個別許可を行います。

## 初回に「開発元を確認できない」と表示されたとき

公式の案内・GitHubから取得した「こえのたね」であることを確認して操作してください。

1. アプリを一度開こうとした後、Macの「システム設定」を開きます。
2. 「プライバシーとセキュリティ」を開き、下の「セキュリティ」付近までスクロールします。
3. 「こえのたね」の表示を確認し、「このまま開く」を押します。
4. 確認画面で「開く」を選びます。Macの認証が表示された場合は、ご自身で認証します。

これは対象アプリだけの初回許可です。セキュリティ機能全体をオフにしたり、ターミナルのコマンドを実行したりする必要はありません。管理対象Macでは、管理者の制限で許可できない場合があります。

Apple公式の説明：https://support.apple.com/ja-jp/102445

## Fnキーで音声入力する準備

1. アプリの「設定」で「日本語モデルを準備」を押します。初回の取得には通信します。
2. 録音ボタンを押し、マイクの使用を許可します。
3. 「入力監視の設定を開く」から、macOSで「こえのたね」をオンにします。
4. 「貼り付けの許可を設定」から、アクセシビリティの「こえのたね」をオンにします。
5. Macのキーボード設定で「🌐キーを押して実行する操作」を「何もしない」にします。
6. 必要に応じてアプリを終了して開き直します。設定に「Fnキーの検知：準備完了」「自動貼り付け：許可済み」と表示されることを確認します。
7. 入力欄をクリックし、Fnを押している間に話し、離します。最初はTextEditの空欄で試してください。

アプリの更新で許可が反映されなくなった場合は、対象の「こえのたね」の登録だけを削除し、アプリケーションフォルダの最新版を追加し直してください。辞書や設定を削除する必要はありません。

## データと文章整形

音声認識はMac内で行い、マイク音声の録音ファイルや認識履歴を保存しません。単語辞書と設定はこのMacに保存します。コピー・自動貼り付けの結果はクリップボードに入ります。

「フィラー除去（ルール）」は標準オンです。「文章整形（Apple Intelligence）」は任意で、オフでも音声入力できます。重要な文章は貼り付け後に確認してください。

## Fnで設定画面に戻る・モデル未準備の場合

日本語音声認識モデルの初回ダウンロードが必要です。入力画面（0.5.0は設定画面）の「日本語モデルを準備」を押し、「準備完了」まで待ってください。Apple Intelligenceの文章整形モデルとは別です。0.5.1では入力画面に不足している準備と実行ボタンを表示します。貼り付けの許可がなくても録音して結果をアプリへ表示できます。

設定が分からない場合は、[公式LPの「AIに設定を頼む場合は」](https://ai-no-tane.com/lp/koenotane/#troubleshooting)から依頼文をコピーし、設定するMacのClaude CodeやCodexへ貼り付けて相談できます。本人認証や許可画面など、AIが操作できない項目は手順を案内してもらってください。
