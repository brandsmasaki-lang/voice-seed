# 検証範囲

開発環境：AppleシリコンM1 / macOS 26.7.1 / Swift 6.4・SDK 27.0 / macOS 26をターゲット。

## 0.3.1までに確認した機能

- テキスト処理8、フィラー除去23、Fn・録音ライフサイクル18、辞書取り込み25、逐次認識結果9の、計83チェックに成功。
- 物理Fn操作から実マイク録音・認識・専用AppKitの入力欄への自動貼り付けを開発Macで確認。
- UTF-8・UTF-16・Shift JIS・CP932、CSV引用符・改行、重複・同音異表記・既存辞書維持を合成の辞書データで確認。
- 合成日本語音声11.129秒をリアルタイムで認識する測定で、音声終了から確定まで約0.50秒（22050Hzモノラル）／約0.20秒（48000Hzステレオ）。最初の途中表示は約1.07秒。各1回の測定で、文章整形や入力先への反映時間を含まない。
- Apple Intelligenceの端末内モデルによる、架空の日本語文の整形を確認。

この測定は精度や速度の保証ではありません。マイク・発話・環境・文章の長さによって変わります。

## 0.4.0の公開準備

- 開発Macで0.4.0（ビルド5）の「アプリについて」を表示し、運営元・X・相談LINE・GitHubの4つのリンク先とレイアウトを確認。
- 既存83チェックと、公開用ファイルの除外・未設定リンク・シンボリックリンクの拒否・認証情報の混入検出の4チェックが成功（計87）。追加チェックは合成ファイルだけを使用。
- 公開用ソースZIPの全ファイルとSHA-256マニフェストを照合。開発用Git履歴・qa・ビルド出力・個人辞書を含めない構成を確認。
- ローカルビルドとアドホック署名検証に成功。Developer ID署名・公証は未実施。

GitHub CIの結果はリポジトリのActionsで確認できます。他のMacでの受け入れ確認は未実施です。
