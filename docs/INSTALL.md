# こえのたねの使い始め方

配布元：株式会社ブランズバンクシステムズ
公式案内：https://ai-no-tane.com/lp/koenotane/
ソースコード：https://github.com/brandsmasaki-lang/voice-seed

対応：AppleシリコンMac（M1以降）・macOS 26以降・日本語。
GitHubの0.7.8以降の正式配布物には、BRANS BANK SYSTEMS, K.K.のDeveloper ID署名とAppleの公証チケットを付けています。0.7.0以前の配布物や、自分でビルドした版は署名・公証の状態が異なります。

## インストール

1. ダウンロードしたDMGを開きます。
2. 「こえのたね」を隣の「アプリケーション」へドラッグします。
3. アプリケーションフォルダの「こえのたね」を開きます。
4. 開発元や公証に関する警告が出る場合は、そのまま開かず、公式リリースのバージョンと配布元を確認してください。

DMGやZIPの展開先から直接起動した場合も、「インストールして開く」でアプリケーションへコピーし、配置先から開き直します。元のダウンロードは残ります。配置先にすでにこえのたねがある場合は上書きせず、インストール済みのアプリを開く案内になります。

管理者の許可が必要なMacでは、Finderでドラッグし、macOSの認証画面に従ってください。権限を与えられていない管理対象Macでは、管理者への確認が必要です。

以後はアプリ内の「更新する」を使います。更新はアプリケーション内で開始し、そのアプリを入れ替えます。ダウンロードフォルダのコピーを更新先にはしません。

## 開発元に関する警告が表示されたとき

GitHubの正式リリースの0.7.8以降を取得しているか確認してください。署名・公証済みの最新版でも警告が出る場合は、表示内容とバージョンをサポートへお知らせください。セキュリティ設定を無効にする操作は不要です。

Apple公式の説明：https://support.apple.com/ja-jp/102445

## Fnキーで音声入力する準備

1. アプリの「設定」で「日本語モデルを準備」を押します。初回の取得には通信します。
2. 音声入力ボタンを押し、マイクの使用を許可します。
3. 入力画面の「音声入力の準備」で「許可する」を押し、開いたアクセシビリティの一覧で「こえのたね」をオンにします。一覧に出てこないときは「＋」を押し、アプリケーションフォルダの「こえのたね」を選びます。
4. 自動貼り付けをオフにして使う場合は、「入力監視を設定する」から「こえのたね」をオンにします。自動貼り付けがオンなら、手順3の許可だけでFnキーの検知も使えます。
5. Macのキーボード設定で「🌐キーを押して実行する操作」を「何もしない」にします。
6. 入力画面に緑の「これで使えます！」が表示されることを確認します。表示されないときは、準備欄の「こえのたねを開き直す」を押します。
7. 入力欄をクリックし、Fnを押している間に話し、離します。最初はTextEditの空欄で試してください。

アプリを更新すると、システム設定では「こえのたね」がオンに見えるのに許可が効かなくなることがあります。オンに見えているのは更新前の版への許可で、今の版には適用されていないためです。この場合は準備欄の「許可をやり直す」を押し、開いた一覧で「こえのたね」をオンにしてください。アプリが古い許可の記録だけを消して申請し直します。辞書や設定は消えません。

## データと文章整形

音声認識はMac内で行い、マイク音声の録音ファイルは保存しません。直近5件の入力履歴と利用統計はMac内に保存し、各画面で保存のオフと削除・リセットができます。単語辞書と設定もこのMacに保存します。コピー・自動貼り付けの結果はクリップボードに入ります。

「フィラー除去（ルール）」は標準オンです。「文章整形（Apple Intelligence）」は任意で、オフでも音声入力できます。重要な文章は貼り付け後に確認してください。

## Fnで設定画面に戻る・モデル未準備の場合

日本語音声認識モデルの初回ダウンロードが必要です。入力画面（0.5.0は設定画面）の「日本語モデルを準備」を押し、「準備完了」まで待ってください。Apple Intelligenceの文章整形モデルとは別です。0.5.1では入力画面に不足している準備と実行ボタンを表示します。貼り付けの許可がなくても録音して結果をアプリへ表示できます。

設定が分からない場合は、[公式LPの「AIに設定を頼む場合は」](https://ai-no-tane.com/lp/koenotane/#troubleshooting)から依頼文をコピーし、設定するMacのClaude CodeやCodexへ貼り付けて相談できます。本人認証や許可画面など、AIが操作できない項目は手順を案内してもらってください。
