# iPhone版の販売・レビュー協力者向け配布

更新日：2026-11-14（日本時間）

## 利用者が決定した方針

- iPhone版：App Storeで買い切り2,980円。月額課金なし。
- Mac版：現在の無料配布を継続。
- ソース：既存のMIT公開方針を維持。
- 配布者：株式会社ブランズバンクシステムズ。法人のApple Developer Program登録をMac版とiPhone版で共用する。
- レビュー協力者へ無料で渡せる配布経路を設ける。
- キャンペーン値下げ・全員向け無料化は可能か確認した段階。期間・価格・実施は未決定。

## 準備する配布経路

1. 公開前の動作確認・感想収集：TestFlightの外部テスター用グループ。招待先は利用者が指定した協力者。配布できるビルドの登録と必要なAppleの審査を終えてから招待する。
2. 正式版の紹介・レビュー用提供：App Storeのアプリ用プロモーションコード。一般向け価格を2,980円のままにして、指定された協力者にコードを個別配布する。
3. コードは配布対象が決まってから必要な数だけ発行する。Apple公式では各プラットフォームの各バージョンにつき最大100枚、発行から4週間以内に1回だけ引き換え可能。引き換え後は購入済みアプリとして更新できる。
4. コード利用者はApp Store内で評価・レビューを書けない。レビュー用提供は、実利用の感想、改善点、記事・動画等での紹介を想定する。アプリ内評価を集める経路とは扱わない。

このコードで入手したアプリは購入済み扱いになります。App Store内での評価・レビュー投稿はできません。記事や動画で紹介される場合は、レビュー用の無償提供を受けたことが分かる形でお願いします。

## 現時点の実行状況

- Apple Developerへの本人サインイン完了。画面のApple Developer Agreementは本人からその契約への明示同意を受け、Agreeを押して完了。任意プロフィールは後回しにした。
- 本人情報の入力、企業／組織の選択、D-U-N-S照合、会社ドメインのメール認証が完了。所有者／創立者として契約権限を持つことを本人に確認した。
- 法人登録の申請を送信し、Apple画面の「現在登録を処理しています」を確認済み。Appleによる署名権限の確認待ち。確認後、登録完了までの手順がメールで届く。
- 有料Program契約・年会費の支払い・会員資格の有効化は未完了。申請受付を加入完了として扱わない。
- App Store Connectのアプリ登録、価格設定、TestFlight配布、プロモーションコード発行・送信は未実施。
- 契約同意が必要な画面では、その具体的な契約を提示して本人の同意を確認する。
- アカウント・法人の認証情報、D-U-N-S番号、コード、配布先の個人情報はこの文書や公開ソースへ保存しない。
